| 채팅 / 명령어 | 명령어 검색·키보드 선택·모델 변경·세션/실행 조작 | 브라우저 UI 스모크 테스트 포함 |

**기능 명칭과 실제 검증 범위를 분리한다.** 모델이 없으면 모델 응답을 시뮬레이션하지 않는다. CI가 녹색이더라도 사용자 로컬 LM Studio·Discord·OAuth까지 검증했다는 뜻은 아니다.
