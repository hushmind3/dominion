이용약관

시행일 2026년 11월 19일 · 버전 1.0

이 약관은 도미니온(이하 “운영자”)이 운영하는 웹사이트 dominionai.kr과 오픈소스 데스크톱 애플리케이션 DOMINION(이하 “소프트웨어”)의 이용에 관한 조건을 정합니다. 소프트웨어는 현재 유료 결제나 구독 없이 무료로 공개된 개발자 프리뷰이며, 소스코드는 MIT 라이선스로 공개되어 있습니다.

제1조 (목적과 적용 범위)

이 약관은 운영자가 제공하는 웹사이트와 소프트웨어의 이용 조건과 절차, 운영자와 이용자의 권리·의무 및 책임 사항을 정하는 것을 목적으로 합니다.

웹사이트는 소프트웨어의 소개, 설치 파일 안내, 문서 링크를 제공하는 정보 페이지입니다. 회원가입이나 로그인 절차는 없습니다. 소프트웨어는 이용자가 자신의 컴퓨터에 직접 설치해 실행하는 데스크톱 애플리케이션이며, 운영자는 이용자의 실행 환경을 제공하거나 관리하지 않습니다.

제2조 (용어의 정의)

  • 웹사이트: 운영자가 dominionai.kr 도메인으로 제공하는 정보 페이지를 말합니다.
  • 소프트웨어: DOMINION이라는 이름으로 공개된 오픈소스 데스크톱 애플리케이션과 그 실행 파일을 말합니다.
  • 이용자: 웹사이트를 열람하거나 소프트웨어를 내려받아 설치·실행하는 사람을 말합니다.
  • 모델 제공자: 이용자가 소프트웨어에 연결하는 외부 AI API 사업자 또는 로컬 모델 실행 환경을 말합니다.
  • API 키: 모델 제공자 등이 발급한 접근 자격 증명으로, 이용자가 직접 발급받아 소프트웨어에 등록하는 값을 말합니다.

제3조 (약관의 효력과 변경)

이 약관은 웹사이트에 게시함으로써 효력이 발생합니다. 운영자는 관련 법령을 위반하지 않는 범위에서 약관을 변경할 수 있으며, 변경된 약관은 시행일과 함께 웹사이트에 게시합니다.

이용자에게 불리한 중요한 변경이 있는 경우에는 시행일 이전에 웹사이트를 통해 알립니다. 변경된 약관의 시행일 이후에도 웹사이트를 이용하거나 소프트웨어를 내려받아 사용하는 경우 변경된 약관에 동의한 것으로 봅니다.

제4조 (제공하는 것)

운영자는 다음과 같은 것을 무료로 제공합니다.

  • 소프트웨어의 소개와 기능, 설치 방법, 요구 사항을 정리한 웹사이트 정보
  • 소프트웨어 설치 파일과 소스코드로의 링크 (설치 파일은 GitHub 릴리스에서 배포됩니다)
  • 이용 문의에 대한 이메일 응대

소프트웨어 사용에 필요한 모델 사용료, 서버 비용, 장비와 통신 비용은 이용자가 부담합니다. 운영자는 모델 제공자와 이용자 사이의 계약 당사자가 아닙니다.

현재 유료 상품, 정기 구독, 별도 지원 계약은 없습니다. 운영자가 유료 서비스를 시작하는 경우에는 그 내용과 조건을 별도로 안내합니다.

제5조 (오픈소스 라이선스)

소프트웨어의 소스코드는 MIT 라이선스로 공개되어 있습니다. 라이선스 전문은 저장소의 LICENSE 파일 ↗에서 확인할 수 있습니다.

소스코드의 복제, 수정, 배포, 사용 조건은 MIT 라이선스가 정한 바에 따릅니다. 이 약관과 MIT 라이선스의 내용이 다르면, 소스코드의 이용에 관해서는 MIT 라이선스가 우선합니다. 다만 웹사이트의 문서와 이미지, 소프트웨어의 이름과 로고에는 제10조가 적용됩니다.

MIT 라이선스에 따라 소프트웨어는 저작권 고지와 허락 고지를 포함한 상태로 제공되며, 수정한 버전을 배포하는 사람은 그 사실을 표시해야 합니다.

제6조 (이용자의 책임)

소프트웨어는 이용자의 컴퓨터에서 실행되고, 모델 호출과 도구 실행은 이용자의 환경에서 이루어집니다. 다음 사항은 이용자의 책임입니다.

  • API 키와 계정 관리: 이용자가 등록한 API 키의 보관과 사용, 키가 노출되지 않도록 하는 조치. 키는 이용자의 환경에 저장되며 운영자는 이를 제공받지 않습니다.
  • 모델 사용료와 제공자 정책: 모델 제공자의 요금, 사용 한도, 이용약관과 개인정보 처리 방침을 확인하고 준수하는 일. 모델 제공자의 요금 청구는 이용자와 그 제공자 사이의 문제입니다.
  • 도구 실행의 승인과 결과: 소프트웨어는 파일, 셸 명령, HTTP 요청 같은 도구를 실행할 수 있습니다. 실행 전 승인 여부를 판단하고, 실행으로 발생한 변경과 그 결과를 확인하는 일.
  • 백업과 환경 관리: 대화 기록과 기억 데이터가 저장된 로컬 데이터의 백업, 운영체제와 소프트웨어의 업데이트, 실행 권한 설정.
  • 제3자 서비스 약관 준수: 소프트웨어와 함께 사용하는 외부 채널(메신저 봇 등)과 도구 제공자의 정책을 지키는 일.

운영자는 이용자의 컴퓨터에서 실행되는 소프트웨어의 동작을 실시간으로 감독하지 않으며, 이용자가 승인한 도구 실행의 내용을 통제하지 않습니다.

제7조 (보증의 부인)

소프트웨어와 웹사이트의 정보는 있는 그대로(as-is) 제공됩니다. 운영자는 소프트웨어가 특정 목적에 적합하거나, 오류 없이 중단 없이 동작하거나, 모든 운영체제·모델· 채널 조합에서 같게 동작한다고 보증하지 않습니다.

현재 소프트웨어는 개발자 프리뷰 단계로, 기능과 화면이 예고 없이 바뀔 수 있으며 일부 기능은 모의 모델을 사용한 검증에 기반합니다. 웹사이트에 적힌 릴리스 번호와 설치 파일 목록은 실제 릴리스 시점에 따라 달라질 수 있으므로, 내려받기 전에 GitHub 릴리스 노트를 확인해 주세요.

제8조 (책임의 제한)

운영자는 무료로 제공되는 소프트웨어와 웹사이트의 이용과 관련하여 발생한 다음의 손해에 대해 책임을 지지 않습니다. 다만 운영자의 고의 또는 중대한 과실로 인한 손해와 관련 법령상 책임을 배제할 수 없는 손해에 대해서는 그러하지 않습니다.

  • 이용자의 데이터, 파일, 설정의 손실 또는 손상
  • 모델이 생성한 결과의 정확성, 완전성, 특정 목적 적합성
  • 모델 제공자 또는 외부 채널 제공자의 서비스 중단·장애·요금 변경
  • 이용자가 승인한 도구 실행으로 발생한 결과
  • 소프트웨어 사용으로 발생한 간접손해, 특별손해, 결과적 손해, 기대 이익의 상실

이 조항은 소비자 보호에 관한 법령이 정한 이용자의 권리를 제한하지 않습니다.

제9조 (금지 행위)

이용자는 다음 행위를 해서는 안 됩니다.

  • 관련 법령을 위반하거나 범죄를 돕는 목적으로 소프트웨어나 웹사이트를 이용하는 행위
  • 타인의 저작권, 상표권, 개인정보, 계정을 침해하는 행위
  • 악성코드 배포, 무단 접근, 서비스 방해 등 타인에게 피해를 주는 목적으로 사용하는 행위
  • 다른 사람의 API 키나 접근 자격 증명을 무단으로 사용하는 행위
  • 변조한 빌드를 공식 배포본으로 오인하게 표시하거나, 운영자 또는 DOMINION의 승인을 받은 것처럼 홍보하는 행위
  • 웹사이트나 소프트웨어의 취약점을 이용해 다른 이용자의 정보를 얻거나 시스템을 훼손하는 행위

소프트웨어가 오픈소스로 공개되어 있다는 사실은 위 행위를 허용하지 않습니다. 금지 행위로 발생한 문제의 책임은 그 행위를 한 사람에게 있습니다.

제10조 (지식재산권과 명칭)

웹사이트의 문서, 이미지, 디자인과 소프트웨어의 이름 및 로고에 대한 권리는 운영자에게 있습니다. MIT 라이선스는 소스코드의 이용을 허락하는 것이며, DOMINION의 이름과 로고를 자신의 제품명이나 공식 배포본처럼 사용할 권리를 함께 주는 것은 아닙니다.

소프트웨어를 수정해 배포하려는 경우에는 원본과 다른 버전임을 알 수 있게 표시하고, 원본 저장소를 함께 밝혀 주세요.

제11조 (서비스의 변경과 중단)

운영자는 웹사이트의 내용을 바꾸거나, 소프트웨어의 개발과 배포를 중단할 수 있습니다. 중단하는 경우에는 가능한 범위에서 웹사이트에 미리 알립니다.

개인 프로젝트로 운영되는 만큼 응대까지 시간이 걸릴 수 있습니다. 이미 내려받은 소프트웨어는 MIT 라이선스에 따라 계속 사용할 수 있지만, 새 버전의 제공이나 오류 수정이 보장되지는 않습니다.

제12조 (준거법과 분쟁 해결)

이 약관은 대한민국 법률에 따라 해석되고 적용됩니다. 운영자와 이용자는 분쟁이 생기면 먼저 상호 협의로 해결하도록 노력합니다. 협의가 이루어지지 않는 경우에는 민사소송법이 정한 관할 법원에 소를 제기할 수 있습니다.
