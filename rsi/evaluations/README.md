# 과거 RSI 평가 프로필 보관 기록 (실행 기능 종료)

**2026-11-16 이후 이 디렉터리는 실행 설정이 아닙니다.** 내장 RSI 세대 반복, 자동 소스 변경·선택·채택 및 `rsi_frozen_oracle` 실행기는 `dominion-sub2`의 현재 코드에서 제거되었습니다.

`default.json`은 당시 연구·평가 계약을 이해하기 위해 **내용을 변경하지 않은 역사 자료**로 보존합니다. 현재 사용자 설정·작업 실행·자동 평가에 연결하지 않습니다. 실행되지 않는 원본의 `src/engine/rsi_evolve.rs`, `src/engine/rsi_oracle_fixture.rs` 등을 다시 만들거나 이 프로필을 활성화하지 마세요.

실제 개발·검증은 사용자 요청에 따른 기존 Rust 하네스 수정과 독립적인 개발 프로파일 회귀 테스트를 사용합니다. 과거 데이터 조회는 `/api/rsi/*`의 읽기 전용 호환 API에서만 제공합니다.
