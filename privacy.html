개인정보처리방침

시행일 2026년 11월 19일 · 버전 1.0

도미니온(이하 “운영자”)은 웹사이트 dominionai.kr과 오픈소스 데스크톱 애플리케이션 DOMINION을 운영하면서 처리하는 개인정보의 항목과 목적, 보유 기간, 이용자의 권리를 아래와 같이 안내합니다. 웹사이트는 회원가입이 없고 쿠키나 방문자 추적 도구를 사용하지 않으며, 앱은 이용자의 PC에서 로컬로 동작합니다.

제1조 (총칙과 적용 범위)

이 방침은 운영자가 웹사이트를 제공하고 이메일 문의에 응대하는 과정에서 처리하는 개인정보와, 이용자가 자신의 컴퓨터에서 소프트웨어를 실행할 때 데이터가 어떻게 다루어지는지를 설명합니다.

소프트웨어는 이용자의 컴퓨터에서 실행되며, 운영자는 이용자의 대화 내용이나 작업 기록을 전달받지 않습니다. 다만 이용자가 소프트웨어에 연결한 모델 제공자나 외부 채널에는 이용자의 요청이 전송될 수 있고, 그 처리는 해당 제공자의 방침을 따릅니다.

제2조 (웹사이트에서 처리하는 정보)

웹사이트는 정적인 정보 페이지로, 다음과 같은 정보를 스스로 수집하지 않습니다.

  • 회원가입, 로그인, 댓글 등 이용자가 입력하는 개인정보를 받지 않습니다.
  • 쿠키, 광고 식별자, 방문자 분석 도구(액세스 로그 분석 포함)를 사용하지 않습니다.
  • 운영자는 접속 기록·방문 통계를 수집해 보관하는 기능을 두지 않았습니다. 사이트 전달에 필요한 범위의 기술적 기록만 호스팅 사업자가 처리합니다.

호스팅과 내려받기 확인

웹사이트는 Cloudflare, Inc.의 호스팅·전송 서비스를 통해 제공되며, 접속 과정에서 접속 IP, 브라우저 정보, 요청 시각 같은 기술적 기록이 처리될 수 있습니다. 이는 사이트를 전달하기 위해 필요한 처리이며, 해당 사업자의 개인정보 처리 방침이 적용됩니다.

설치 파일은 GitHub, Inc.의 릴리스 페이지에서 내려받습니다. 내려받기 버튼에 표시되는 최신 버전을 확인하기 위해, 방문자의 브라우저가 GitHub의 공개 API(api.github.com)에 직접 요청을 보내며 이때 방문자의 IP가 GitHub에 전달됩니다. 자바스크립트를 끄거나 스크립트가 실행되지 않는 환경에서는 이 요청 없이 GitHub 릴리스 페이지로 연결됩니다.

제3조 (이메일 문의 시 처리하는 정보)

문의 메일을 보내는 경우, 운영자는 응대를 위해 다음 정보를 처리합니다.

  • 처리 항목: 보낸 사람의 이메일 주소, 메일 본문에 적힌 이름이나 소속 등 이용자가 직접 밝힌 정보, 문의 내용과 첨부 파일
  • 처리 목적: 문의에 대한 답변, 오류 확인과 안내, 필요 시 이용자와의 연락
  • 보유 기간: 응대가 끝난 뒤 지체 없이 파기합니다. 다만 같은 문의가 반복되거나 분쟁이 진행 중인 경우에는 처리가 끝날 때까지 보관할 수 있습니다.
  • 처리 근거: 이용자가 문의를 위해 자발적으로 보낸 정보에 대한 응대

문의 메일에는 주민등록번호, 계좌번호, 비밀번호, API 키 같은 민감한 값을 적지 마세요. 오류를 알리려고 화면을 캡처할 때에는 개인정보가 보이지 않게 가려 주세요.

제4조 (데스크톱 앱의 데이터 처리)

DOMINION은 로컬 우선으로 동작합니다. 운영자는 앱 사용 기록을 수집하는 분석·추적 도구를 넣지 않았고, 이용자의 대화 내용을 운영자에게 보내는 기능도 없습니다.

  • 대화와 기억: 대화 기록, 도구 실행 결과, 이용자의 정정 내용은 이용자 PC의 로컬 데이터베이스(SQLite)에 저장됩니다.
  • API 키: 이용자가 등록한 모델 API 키는 이용자의 PC에 저장되며, 운영자는 이를 제공받지 않습니다. 키는 이용자가 선택한 모델 제공자와의 통신에만 사용됩니다.
  • 모델 호출: 이용자가 클라우드 API를 연결하면 요청 내용이 해당 제공자에게 전송됩니다. 어떤 내용이 전송되고 얼마나 보관되는지는 이용자가 고른 제공자의 약관과 개인정보 처리 방침에 따릅니다. 로컬 모델을 사용하면 요청이 외부로 나가지 않습니다.
  • 외부 채널: Telegram, Discord 같은 채널을 직접 연결한 경우, 그 채널을 통해 주고받은 내용은 해당 서비스에 저장됩니다.
  • 도구 실행: 파일, 셸, HTTP 도구는 이용자가 승인한 범위에서 이용자의 PC에서 실행되며, 그 결과는 로컬에 기록됩니다.

앱을 삭제하거나 로컬 데이터를 지우면 해당 기록은 이용자의 PC에서 사라집니다. 백업과 삭제는 이용자가 직접 관리합니다.

제5조 (제3자 제공)

운영자는 이용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다. 법령에 따라 수사기관 등이 적법한 절차로 요청하는 경우에는 그 절차에 따를 수 있습니다.

문의 메일로 받은 내용은 응대 목적 범위에서만 사용하며, 이용자의 동의 없이 다른 목적으로 이용하거나 외부에 공개하지 않습니다.

제6조 (처리 위탁과 국외 이전)

운영자는 웹사이트 운영과 이메일 응대를 위해 아래 서비스를 이용하며, 이 과정에서 필요한 범위의 정보가 국외로 이전될 수 있습니다.

  • GitHub, Inc. (미국) — 설치 파일·소스코드 배포 및 내려받기 정보 확인. 이전 항목: 접속 IP, 브라우저 정보, 요청 기록
  • Cloudflare, Inc. (미국) — 웹사이트 호스팅·전송과 보안. 이전 항목: 접속 IP, 요청 기록
  • Google LLC (미국) — 문의 이메일 수신과 보관(Gmail). 이전 항목: 이메일 주소, 문의 내용

각 사업자의 처리 방침은 해당 사업자의 웹사이트에서 확인할 수 있습니다. 이전을 원하지 않는 경우 문의 이메일 대신 공개 저장소의 이슈를 이용할 수 있으나, 이슈 내용은 공개됩니다.

제7조 (보유 기간과 파기)

개인정보는 처리 목적을 달성하면 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 삭제하고, 종이 문서가 있는 경우에는 분쇄합니다.

관련 법령이 보존을 요구하는 경우에는 해당 법령이 정한 기간 동안 보관한 뒤 파기합니다. 현재 운영자는 별도의 회원 데이터베이스를 운영하지 않으므로, 상시 보관하는 개인정보는 문의 메일함에 남아 있는 응대 기록이 전부입니다.

제8조 (이용자의 권리)

이용자는 자신의 개인정보에 대해 다음을 요청할 수 있습니다.

  • 처리 항목과 내용의 열람
  • 오류가 있는 정보의 정정
  • 삭제와 처리 정지

요청은 hushmind@gmail.com으로 보내 주세요. 본인 확인이 가능한 범위에서 지체 없이, 늦어도 10일 이내에 처리 결과를 알려 드립니다. 앱이 이용자 PC에 저장한 데이터는 이용자가 직접 삭제할 수 있으며, 운영자는 해당 데이터를 보유하고 있지 않아 대신 삭제해 드릴 수 없습니다.

제9조 (안전성 확보 조치)

  • 웹사이트와 이메일 응대에 필요한 최소한의 정보만 처리합니다.
  • 웹사이트는 HTTPS로 전송되며, 호스팅 사업자의 보안 기능을 함께 사용합니다.
  • 문의 응대에 사용하는 계정의 접근 권한을 운영자 본인으로 한정하고, 2단계 인증과 같은 추가 보호 수단을 사용합니다.
  • 앱의 API 키와 로컬 데이터는 이용자의 PC에 있으므로, PC 계정과 디스크 암호화 등 이용자 환경의 보안 설정이 함께 필요합니다.

제10조 (아동의 개인정보)

웹사이트와 소프트웨어는 만 14세 미만 아동을 대상으로 하지 않으며, 운영자는 아동의 개인정보를 의도적으로 수집하지 않습니다. 아동의 정보가 문의 과정에서 처리된 사실을 알게 되면 지체 없이 파기합니다.

제11조 (방침의 변경)

이 방침의 내용이 바뀌면 시행일과 함께 이 페이지에 게시합니다. 처리 항목이나 목적이 실질적으로 달라지는 경우에는 시행일 이전에 웹사이트를 통해 알립니다.
